## Retained boundaries

| Boundary          | Source contract                                                                                                                                                      | Current implementation                                                              | Catalogue treatment                                                                                            |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Origin / CSRF     | [README host rules](../README.md#rules-the-host-must-keep) require rejecting foreign `Origin` or `Sec-Fetch-Site` before issuance.                                   | Service has no HTTP route and does not inspect request origin.                      | US-CONFIRM-01 assigns this check to the host; it does not claim package enforcement.                           |
| Throttling        | [README host rules](../README.md#rules-the-host-must-keep) specify limiter defaults and the host obligation when `throttle: false`.                                  | Service uses the application's `@adonisjs/limiter` manager, or no built-in limiter. | US-CONFIRM-01 records the required host throttle when disabled.                                                |
| Cleanup cadence   | [README usage](../README.md#usage) tells the host to schedule pruning.                                                                                               | `prune()` exists; no scheduler/command is included.                                 | US-CONFIRM-05 assigns cadence to the operator.                                                                 |
| Database evidence | [README support table](../README.md#supported-adonisjs-versions) says SQLite is tested and PostgreSQL is expected but untested.                                      | Source uses Lucid query operations and has no broad verified-dialect claim.         | Stories preserve this evidence limit and do not claim runtime coverage.                                        |
| Session store     | [README support table](../README.md#supported-adonisjs-versions) requires a server-side session store; the cookie store keeps a copied session alive after sign-out. | Package does not detect the store type.                                             | US-CONFIRM-01 lists it under Access; US-CONFIRM-02, 03 and 04 reference it; no package enforcement is claimed. |

The throttled exception sets the retry header and renders the negotiated response when handled by AdonisJS. [US-CONFIRM-06](US-CONFIRM-06-recover-from-throttling.md) covers this boundary. Existing 0.1.1 hosts supply a later migration and discard earlier proofs as described in [US-CONFIRM-07](US-CONFIRM-07-upgrade-confirmation-storage.md). The isolated installed-consumer gate exercises SQLite and specific compiler versions, as recorded in [US-CONFIRM-08](US-CONFIRM-08-verify-release-archive.md).
